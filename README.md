# APILens

APILens is a reproducible named-entity recognition project for identifying and classifying Python API mentions in official library documentation.

> The dataset and benchmark are under construction. All reported numbers will be generated from versioned project artifacts rather than estimated manually.

## Setup

Install the CUDA build of PyTorch for your GPU first (see https://pytorch.org/get-started/locally/); it is not pinned in `requirements.txt`. Then:

```bash
pip install -r requirements.txt
```
